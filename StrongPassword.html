Strong Password Generator

Generate secure random passwords or memorable passphrases locally.

Settings

Choose a mode based on whether compactness or memorability matters more.

Random password

Every enabled character set is represented at least once. Weights control the relative chance of selecting a set for the remaining characters; a zero weight disables it.

Memorable passphrase

Passphrases use a word count instead of a character limit. The four-word default provides about 41.4 bits from word selection alone; increase the word count when stronger offline-guessing resistance matters.

The bundled list will be loaded when needed.

Bundled source: EFF Short Wordlist for Passphrases #1 (CC BY 4.0 under EFF's published copyright policy).

Output

Click a result to select it, then copy.

Random choices use crypto.getRandomValues(). Everything runs locally; selected word-list files are not uploaded.
